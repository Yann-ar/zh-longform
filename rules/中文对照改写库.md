# 中文对照改写库

> 本库收集本项目在长文写作、翻译引进与模型生成中真实暴露的欧化机翻与病句病例，每条提供「病句 -> 问题诊断 -> 地道改句」。写作前必读，独立审读时作为强制挑错清单使用。退稿即教材，持续扩充。

## 一、 超长定语包夹与从句硬塞（最常见欧化假通顺）

| 病句（假通顺/读不顺） | 问题诊断 | 地道改句（讲人话） |
| --- | --- | --- |
| 早在 2022 年，我写过一篇关于第一次搬到陌生城市、以及伴随而来的所有令人手足无措的琐碎麻烦的长文。 | 英文 about... and all the... 嵌套定语硬套，长达 20 字修饰包夹 | 2022 年刚搬到陌生城市那会儿，我写过一篇长文，吐槽租房办卡有多折腾。 |
| 这是一款由独立开发者开发的、能够帮助你在碎片时间里高效记录想法的极简卡片笔记软件。 | 把作者、场景、功能硬塞进一个长定语中，一口气读不完 | 这款卡片笔记软件很小巧，是独立开发者做的，专门用来随手记点碎片想法。 |
| 在那个当下，我对那台旧相机怀有的是一个人所能体会到的最纯粹、毫无杂质的喜爱。 | 直译 "what I felt was..."，倒装生硬，文绉绉不像活人说话 | 那一瞬间，我是真喜欢那台旧相机，喜欢得不得了。 |
| 成年人仅仅依靠每天被动刷短视频就能无师自通掌握一整套流行语，这种超凡的学习机制完全超出了我的理解范畴。 | "超出了我的理解范畴" 为机翻套话，句子头重脚轻 | 大人光靠天天刷短视频，就能学会一整套流行语。这本事我到现在都想不通。 |
| 在这个封闭的气泡里，爱好者很容易彻底丧失现实感，忘记对全世界绝大多数普通人来说，机械键盘轴体的细微差别无趣到了令人窒息的地步。 | 英文状语与从句多层嵌套，呼吸节奏彻底断裂 | 玩久了键盘，人就容易活在自己的小圈子里。你根本想不起来，在外人眼里，轴体那点差别到底有多无聊。 |
| 这是一个当你需要处理大量格式混乱的 Markdown 文本时会感到极其省心的自动化脚本。 | 英文 when 从句生译，定语超载 | 平时要是经常整理格式乱七八糟的 Markdown 文本，跑一下这个小脚本会很省心。 |
| 作为一个长期饱受颈椎酸痛困扰的程序员，我在选购升降桌时最看重的指标是电机的升降平稳度。 | "作为一个……" 典型翻译腔开场，缺乏身体直接感触 | 码字久了脖子酸，我挑升降桌就看一条：升降稳不稳。 |
| 那些被精心收藏在浏览器书签栏深处却再也没有被点开过的技术长文…… | 英文定语从句倒装修饰，阅读阻力大 | 很多技术文章随手存进书签栏，就再也没点开过。 |
| 这是一个能够把复杂的命令行配置过程简化为图形界面一键点击操作的开源小工具。 | 英文 that can... 结构直译 | 这个开源小工具把繁琐的命令行配置，做成了一个点一下就搞定的图形界面。 |
| 乔布斯生前亲自构想的最后一个项目不是改变世界的硬件，而是一张没人要的纸质贺卡。 | "构想" 与 "没人要" 口感生硬 | 乔布斯生前最后操盘的项目，不是什么改变世界的新硬件，而是一张没人买单的纸质贺卡。 |

## 二、 伪名词化与动词瘫痪（机器味核心病灶）

| 病句（假通顺/读不顺） | 问题诊断 | 地道改句（讲人话） |
| --- | --- | --- |
| 通过对多种不同输入法进行综合维度的对比分析…… | "通过对……进行分析" 废词堆叠，动词瘫痪 | 我把常用的几款输入法挨个测了一遍…… |
| 安装该插件后，可以实现对本地笔记文件的自动备份与云端同步操作。 | "实现对……的……操作" 公文八股 | 装好插件，本地笔记就能自动备份、同步到云端。 |
| 面对模型切换成本过高的问题，很多人会选择进行工具的更换，而不是配置的修改。 | 把好端端的动词变成名词串（更换、修改） | 模型换起来太麻烦，很多人宁可换软件，也懒得改配置。 |
| 对系统设置进行重新调整，能够起到提升整体运行流畅度的作用。 | "起到……的作用" 虚词堆积 | 重新调一下系统设置，电脑跑起来会更顺溜。 |
| 施乐在 1979 年做出的这一决定，造成了后续十余年个人电脑市场格局的根本性改变。 | "做出的决定造成了改变" 缺乏力量感 | 施乐 1979 年这一松口，彻底改写了后十几年个人电脑的天下。 |
| 这一功能为用户提供了极大的便利性。 | 抽象名词 "便利性" 属于打官腔 | 这个功能用起来特别顺手。 |
| 经过对历史账本的查验与计算，可以得出这一业务具有极高盈利能力的结论。 | 经院式公文废话 | 翻开当年的账本算一算，这门生意暴利得惊人。 |
| 缺乏社交掩饰机制，猫的行为完全受瞬时生理冲动的支配。 | 伪学术大词包装，脱离真实生活语境 | 猫不懂客套，想干嘛就干嘛，全凭本能。 |
| 我们可以通过执行如下命令来完成对依赖包的下载与部署。 | "通过执行命令完成部署" 机械教条 | 跑下面这行命令，就能把依赖包装好。 |
| 这一设计带来了注意力分散程度的显著降低。 | 英文 reduction in distraction 直译 | 这么一改，人就不容易分心了。 |

## 三、 介词泛滥、连接词僵化与被字句滥用

| 病句（假通顺/读不顺） | 问题诊断 | 地道改句（讲人话） |
| --- | --- | --- |
| 对于大部分上班族而言，在日常通勤的过程中…… | "对于……而言在……过程中" 连环介词病 | 每天上下班路上…… |
| 一方面通勤时间变长了，但另一方面新公司的工作确实比旧公司要轻松得多。 | 刻板对称套路 "一方面……另一方面" | 通勤虽然变长了，但新公司的活确实比旧公司省心。 |
| 正因如此，伴随着该政策的出台，场馆方获得了巨大的利益空间。 | 僵硬死板的因果连接词 | 这么一来，规矩一定，场馆方就赚得盆满钵满。 |
| 配置参数被写入文件之后，后台服务程序会被系统自动重新启动。 | 连环 "被" 字句，极其难受的欧化被动 | 只要把新参数写进文件，后台服务就会自动重启。 |
| 这一问题在近期被许多用户在社交媒体上反复提及。 | 英文 passive voice 硬搬 | 最近不少人在社交媒体上吐槽这个问题。 |
| 尽管该方案在初期需要投入较多的学习成本，但是一旦熟练掌握之后便能极大地节省精力。 | 经院化 "学习成本与精力" | 这套方案刚上手有点费劲，可一旦用熟了，能省不少心。 |
| 在没有公网 IP 的情况下，我们可以利用内网穿透技术来达到异地访问的目的。 | "在……情况下达到……目的" 假通顺 | 没有公网 IP 也不要紧，做个内网穿透，在外头照样能连回家。 |
| 与此同时，值得注意的是，该功能仅在最新版本中提供支持。 | 烂俗的自媒体过渡套话 | 不过要注意，只有升级到最新版才有这项功能。 |
| 他的演讲稿被苹果的高管们多次进行了修改与删减。 | 被动加公文体 | 苹果的高管们把他的演讲稿改了又改，删掉不少段落。 |
| 这一现象被认知科学家们称为「解释深度幻觉」。 | 欧化被字句 | 认知科学家管这种现象叫「解释深度幻觉」。 |

## 四、 英文生造概念硬译与概念黑话（不知所云）

| 病句（假通顺/读不顺） | 问题诊断 | 地道改句（讲人话） |
| --- | --- | --- |
| 二战隔都里的逃生地道 | 学术生僻词（Ghetto）硬套，读者以为是地名 | 二战纳粹隔离营里的逃生地道 / 祖辈在二战集中营挖地道逃生 |
| 如果我身上的魔力消失了 | 商业直觉（lose the magic）直译为哈利波特式魔力 | 如果有一天我这套直觉失灵了 / 敏锐感消失了 |
| 新泽西大屠杀建筑商 | 歧义直译（以为是制造屠杀的凶手） | 新泽西「大屠杀幸存者建筑商」 |
| 从白俄罗斯地道到 OpenAI 董事会政变 | 英文压缩短语（Belarus tunnel）字面直译 | 从二战集中营里的逃生地道，到重金押注 OpenAI 的董事会变局 |
| 一个逃离物理砖头的家族资本寓言 | 英文 bricks-and-mortar 直译为 "物理砖头" | 一个避开实体地产宿命的科技投资样本 |
| 逃离物理砖头羁绊的制度逃逸 | 英文 institutional escape 学术黑话硬搬 | 彻底避开重资产带来的债务绞索与政治泥潭 |
| 带来了一句充满生理性恐慌的发问 | 英文 visceral panic 直译，生硬造词 | 问出了一个让他深感焦虑的问题 |
| 在硅谷和华尔街的世俗标尺里 | 英文 conventional metrics 硬译 | 在外界的普遍标准看来 |
| 纸张提供的是稳定的界面 | 纸被机械套用为屏幕概念 | 纸张提供的是固定的页面和物理位置 |
| 挡干扰 App 能减少手机拖拽 | drag-and-drop 误译 | 能减少手机对你的注意力拉扯 |

## 五、 虚空假深刻、爹味升华与句式复读

| 病句（假通顺/读不顺） | 问题诊断 | 地道改句（讲人话） |
| --- | --- | --- |
| 每一个红色箭头都精准击中中年人的精神软肋，让我整天沉浸在无处可逃的虚无与存在主义恐慌之中。 | 堆砌假大空哲学词汇，缺乏具体生活痛感 | 体检报告上每多一个向上的箭头，我就心虚一次，像是被一张纸提醒自己正在变老。 |
| 在世俗的标尺里，他已经获得了世人梦寐以求的成功，然而在他内心深处…… | 译制片解说腔 | 在外人眼里，他要名有名、要钱有钱；但他自己心里最清楚…… |
| 这不仅是一次硬件的升级，更是一场关于数字时代人类注意力归宿的深刻反思。 | 新华字典对仗式假深刻，空洞宏大 | 换了这台设备，不仅桌面清爽了，最重要的是我终于能安安静静看会儿书了。 |
| 时代的车轮滚滚向前，留给我们的唯有不断适应变化的从容与笃定。 | 高考作文套话，导师爹味 | 工具天天在变，咱们只要抓住手头最要紧的活儿，就不用瞎焦虑。 |
| 面对生活荒诞的底色，我们最终只能在内心的废墟上建立起属于自己的意义之塔。 | 虚无缥缈的自恋式抒情 | 既然生活总有添堵的时候，不如在书桌前安顿好自己，做点有意思的小东西。 |
| 这是一场在资本调度意志与技术乌托邦狂想之间的精巧合谋。 | 媒体大词拼凑 | 投资人想套现分钱，工程师想做大模型，两边一拍即合。 |
| 他冷冷地抛出一句冰冷的话语，眼神中透露出不可动摇的决绝。 | 脑补网文式神态动作，假分镜 | 他只回了一句话，没有任何商量余地。 |
| 历史露出了它残酷的獠牙，将最初的美好童话彻底撕碎在聚光灯下。 | 低质文艺腔修辞 | 当年的童话讲得有多动听，现实里的丑闻曝光时就有多难堪。 |
| 生活并没有赋予我们坐等答案揭晓的特权。 | 爹味发号施令 | 别干坐着等答案，动手做了才知道。 |
| 它解决「开始计时」；不解决你今天到底该先做什么……它解决的是……而不是…… | 模版句式连续复读十几次 | 换不同句型：它管的是计时；它管不了你先做什么；它的边界在…… |

## 六、其他病例

以下病例原本散在《中文写作生成指令》和《中文媒体语序与表达》中，合并时移到这里。

| 病句（假通顺/读不顺） | 问题诊断 | 地道改句（讲人话） |
| --- | --- | --- |
| 因此，它真正提供的不是自律，而是一个更简单的阅读环境。（节末单独加粗） | 节末加粗对仗格言 | 纸质书无法直接保证专注，但至少在物理上少给了我们几个分心的机会。（自然收束，不加粗） |
| 计时不够，就买番茄钟。坐不住，就买沉浸叙事。总拿起手机，就买屏幕时间管理。 | 「就买」排比复读 | 觉得时间过得没有感知，我们会想要一个番茄钟；一个人坐着容易浮躁，会去挑带陪伴感的叙事软件；忍不住老想摸手机，又会转向防沉迷工具。 |
| 阅读媒介会影响注意力如何分配，而这种影响取决于文本性质。 | 硬译 how 从句 | 阅读媒介会影响我们分配注意力的方式，具体效果则取决于文本难度与阅读习惯。 |
| 通过使用该脚本进行配置，模型切换得以被成功实现。 | 虚词堆叠加被动 | 运行脚本后，即可完成模型切换。 |
| 因为在初学者的头脑中尚未建立起完整的编程抽象概念，所以在面对报错信息的时候，他们往往会表现出超常的慌乱。 | 形合连词与学术腔 | 刚学编程的人脑子里还没有那些抽象概念，一看到报错就慌了。 |
| 通过对多种方案进行综合维度的对比分析，旨在实现为用户提供选型决策的参考依据。 | 伪名词化连环套 | 我把手头的几套方案都试了一遍，挑出最省心的，聊聊该怎么选。 |
| 这是一个能够帮助你在复杂的职场沟通中有效降低注意力内耗的轻量级工具。 | 超长前置定语 | 每天微信消息回不完、脑子发胀的时候，这个轻量小工具能帮你挡掉不少干扰。 |
| 平心而论，这款软件功能很强；然而细看之下露出了破绽；背后的逻辑远比想象复杂…… | 机械辩证三级跳 | 这款软件初看挺唬人，真用上两天，毛病全暴露出来了。 |
| 体验极其糟糕。 | 抽象形容词 | 按键软塌塌的，敲半小时手腕就酸了。 |
| 数据搬迁成本极其庞大。 | 抽象形容词 | 几万张照片搬了一整夜，第二天打开全是乱码。 |
| 令人震惊的智商差距。 | 抽象形容词 | 指着画册跟她重复了三个小时「奶牛怎么叫？哞」。 |
