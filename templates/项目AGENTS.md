# 中文长文写作项目

本项目用 [zh-longform](https://github.com/Yann-ar/zh-longform) Skill 管理从选题到多端发布的流程。规则、模板和脚本都在 Skill 里，这里只放文章。

## 目录

```text
.
├── AGENTS.md              # 本文件
├── 01_选题/选题池.md       # 还没动笔的想法
├── 02_调研/               # 一手材料，资料索引.md 记录出处
├── 03_写作/进行中/<主题>/  # 初稿、配图、审读
└── 05_待发表/<主题>/       # 审读通过的文章、各平台版本、封面、轮播图
```

## 必须守住的几条

- 写稿的上下文不能审自己的稿子，审读交给独立 Subagent。
- 文章状态只记在各篇 frontmatter 的 `status`。
- frontmatter `title`、正文 H1 和 caption 标题逐字一致。
- 封面看图结论由人写，脚本不能代勾。
- 小红书轮播图和卡片只在明确下令后生成。
