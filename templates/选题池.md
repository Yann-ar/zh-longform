# 选题池

只记还没动笔的想法。开始写以后，状态改由文章 frontmatter 记录，这里删掉那一行。立项标准见 Skill 的 `rules/写作规范.md` 第一节。

| 状态 | 选题 | 中心主张（一句能被反驳的话） | 体裁 | 信息增量从哪来 |
| --- | --- | --- | --- | --- |
| 想法 |  |  | 特稿 / 教程 |  |

状态只用三种：想法、调研中、立项。

## 立项前问自己

- 这个观点具体到能被反驳吗？
- 读者看完会改变哪个判断或行动？
- 有没有一手文献、实测记录或真实账本支撑？
- 为什么现在写，而不是半年以后？
