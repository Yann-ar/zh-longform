## 一、阻断清单

### 共通

- [ ] 标题符合三种写法之一，字数达标，frontmatter、H1 和 caption 三处逐字一致。
- [ ] 开头是真实的摩擦、一手物证或账目，没有假想敌，没有虚构的朋友或采访。
- [ ] 没有机械辩证三级跳。
- [ ] 没有脑补的神态、动作或场景。
- [ ] 没有句式复读，同一句型最多出现一次。
- [ ] 没有大词、译制片腔和英文生造词。
- [ ] 没有伪名词化，中心词前的修饰语不超过 12 字，没有连环被字句和介词套话。
- [ ] 长短句交替，每段 2~4 句。
- [ ] 「我」贯穿全文，没有中途变成全知旁白。
- [ ] 结尾没有升华，没有对读者发号施令。
- [ ] 加粗数量达标：特稿 0 处，教程最多 1 处，小节末尾没有格言。
- [ ] 引用块只放真实的一手引语或文书。
- [ ] 盘古之白、直角引号、界面路径写法达标。
- [ ] 外文专有名词第一次出现时附了原文。
- [ ] 涉及钱的地方做了折算，多项对比用了表格。
- [ ] 正文配图全部是真实物证，图注写全内容、年份和出处。
- [ ] 文末有参考来源。
- [ ] 没有一句需要读两遍才懂。

### 特稿

- [ ] 有具体的尺寸、材质、参数、条款或引语，没有用形容词代替。
- [ ] 单方口述、官方未置评、案件进展等事实与法律边界交代清楚，并且写进了叙事。
- [ ] 人物译名、设备代号、事件和术语已对照原文与权威译名，时间对得上，已建 `名词与翻译排查.md`。

### 教程

- [ ] 每一步都写了目的、操作和看到的结果，新手能照做。
- [ ] 至少一处踩坑记录，附真实报错或截图和排查过程。
- [ ] 写了 Token、账单或耗时等真实成本。
- [ ] 写了不适用的场景，以及出问题怎么撤回。
