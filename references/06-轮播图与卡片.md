# 小红书轮播图与策展卡片

规则：`<SKILL>/rules/平台与封面.md` 第三节第 6 小节（轮播图）、第六节（策展卡片）。

**只在用户明确下令时做**，而且文章要已定版、审读通过：

| 用户的话 | 做什么 |
| --- | --- |
| 「出轮播图」 | 只出精简版 |
| 「输出两种轮播图」 | 精简版和全文版都出 |
| 没提 | 一张都不出，交付时也不主动出 |
| 「出卡片」 | 策展卡片（书单、人物思想档案类文章） |

## 精简版（`imgs/xhs/`）

1. 复制 `<SKILL>/templates/小红书图片模板.md` 为文章目录下的 `小红书图片.md`，按 `文章_小红书版.md` 切分：封面卡、正文卡（小标题 + 1~3 段，150 字以内）、引语卡（真实原话 + 出处）。全套 18 张以内。
2. 封面卡自动用 `imgs/cover-source/master.png` 作顶部插画。标题只写核心短语（如「愿我不曾虚度」），其余放副标题，两行各一行排下。
3. 出图并检查：

```bash
python3 <SKILL>/scripts/generate_xhs_slides.py "05_待发表/<主题>" --check
python3 <SKILL>/scripts/generate_xhs_slides.py "05_待发表/<主题>" --replace
```

4. 打开 `imgs/xhs/01.png` 看插画裁切，头、手和关键物件被裁掉就调 `小红书图片.md` 的 `cover_focus`（常用 `0.5,0.55`～`0.5,0.62`）后重出。

## 全文版（`imgs/xhs-full/`）

`文章_小红书版.md` 全文不删减排成图，封面卡和精简版相同，所以要先有 `小红书图片.md` 的封面卡。

```bash
python3 <SKILL>/scripts/generate_xhs_slides.py "05_待发表/<主题>" --full --check
python3 <SKILL>/scripts/generate_xhs_slides.py "05_待发表/<主题>" --full --replace
```

超过 18 张会自动拆成 `第1篇/`、`第2篇/`……，每篇开头都是封面卡。出图后看封面卡、带配图或表格的页面和最后一张。

## 策展卡片（`imgs/cards/`）

文章按第六节第 1 小节写好每个单元的 `<!-- card -->` 数据后：

```bash
python3 <SKILL>/scripts/generate_curated_cards.py --article "05_待发表/<主题>" --palette green --series "系列名"
```

## 注意

- 轮播图文字会被小红书 OCR 识别，`小红书图片.md` 里新写的文字也要避开第三节的敏感词。
- 封面母稿换了以后，轮播图封面卡要重出，但仍要等用户下令。
