# 独立审读

规则：`<SKILL>/rules/写作规范.md` 第九节，模板 `<SKILL>/templates/审读模板.md`。

**写稿的上下文不能审自己的稿子。** 用 Agent 工具开一个全新的 Subagent（general-purpose），不要用 fork（fork 会继承写稿的上下文）。

## 交给 Subagent 的提示词

```text
你是本项目的独立审读方，没有参与这篇文章的写作。

项目根目录：<项目根目录的绝对路径>
Skill 目录：<SKILL 的绝对路径>
审读对象：<文章目录>/文章.md 和 caption.md

先读：
1. <SKILL>/rules/写作规范.md（重点第二至七节和第九节）
2. <SKILL>/rules/中文对照改写库.md
3. <SKILL>/templates/审读模板.md

然后：
- 复制审读模板到 <文章目录>/审读.md，逐项过阻断清单，没打勾的写明行号和问题。
- 逐句列修改表：原句、问题、改句、是否已改。别扭或要读两遍才懂的句子都要列。
- 结论只有「通过」或「退回」，不打分。
- 只改 审读.md，不改 文章.md。
- 重要特稿另建 名词与翻译排查.md，核对外文专有名词的原文和译名。

最后回复：结论、阻断项数量、修改表条数，以及最需要改的三处。
```

## 审读之后

1. 退回：在写稿上下文里按修改表改 `文章.md`，改完再开一个**新的** Subagent 复核，让它在原 `审读.md` 里更新状态和结论，不另写一份。
2. 通过：`status` 改为 `ready`，把整个文章文件夹从 `03_写作/进行中/` 移到 `05_待发表/`，进入 `05-派生与质检.md`。
