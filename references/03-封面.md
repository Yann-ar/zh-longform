# 封面

规则：`<SKILL>/rules/平台与封面.md` 第五节。画风样板：`<SKILL>/assets/style-sample/hawthorne-master.png`。

AI 只画一张约 1:1 的无字母稿，统一用 `<SKILL>/scripts/generate_covers.py` 排出两版：小红书 1440 × 2400、公众号 900 × 383，外加 X 用的 `cover.png`。

## 第 1 步：写提示词

先读正文，挑一个文章里真实发生的具体场景：一个人在做一件具体的事，几件文中提到的物件。不要用齿轮、钱币、地球这类通用符号。

```bash
python3 <SKILL>/scripts/generate_covers.py "05_待发表/<主题>" \
  --prepare --preset <yellow|gray_green|cyan|pink|blue_gray|mint> \
  --scene "具体动作和物件" \
  --relation "这个画面对应正文里的哪件事"
```

- `--relation` 只写和文章的对应关系，不写颜色和风格。
- `--palette-ref <图片>` 可选，只作配色参考。
- 文章还在 `03_写作/进行中/` 时，把路径换成那里。已有提示词要覆盖时加 `--replace`，覆盖前先备份旧文件。

## 第 2 步：画母稿（用户来做）

如果当前环境有能接收参考图的生图工具，就直接用；没有（比如 Claude Code 默认没有），就告诉用户：把 `imgs/prompts/cover-prompt.md` 的正文（`---` 以下）和画风样板**图片文件本身**一起交给生图工具，只画一张。

用户把图发回来后，先和画风样板放在一起看：细铅笔线、密集彩铅排线、低饱和色、环境细节丰富、人物比例自然。不是同一类就请用户重画，不靠排版补救。

## 第 3 步：派生两版

把图存进 `imgs/cover-source/`（webp 先转 png），先预览再覆盖：

```bash
python3 <SKILL>/scripts/generate_covers.py "05_待发表/<主题>" \
  --master "05_待发表/<主题>/imgs/cover-source/<母稿>.png" \
  --layout right-art --focal "0.5,0.5" --lines "第一行/第二行/第三行" --replace
```

- `--focal` 是母稿里主体的位置（0～1），必须落在公众号中心正方形里。
- 自动断行把词拆开（比如「做 / 新东西」）时，用 `--lines` 手动断，必须逐字拼回原标题。
- 预览用 `--output-dir`（要先把 `imgs/prompts/cover-prompt.md` 复制到预览目录同样位置）。
- 覆盖已有封面前，把旧的 `cover*.png`、`master.png`、`封面设计.md` 备份到 `imgs/cover-source/previous-<日期>-<说明>/`。

## 第 4 步：看图（用户来定结论）

自己先看两张成品、终端打印的缩略图和公众号中心裁切，把问题告诉用户：标题区底色是否和插画协调、断行、主体有没有被裁。`封面设计.md` 的打勾和「通过」留给用户，或在用户明确说「通过」之后照实填写。

## 第 5 步：检查

```bash
python3 <SKILL>/scripts/verify_covers.py "05_待发表/<主题>"
```

封面改了以后，如果已经出过轮播图，提醒用户轮播图封面卡也要重出（要用户下令）。
